# 学習アプリ

大学の講義を復習するための、ブラウザで動く学習アプリです。
科目JSONを後から追加し、選択肢・正誤問題、採点、解説、復習を利用できます。

## 使い方

1. 公開URLを開きます。iPhoneはSafariの共有から「ホーム画面に追加」して使えます。
2. 「科目を管理」→「AI用の指示文」をコピーします。
3. 科目名、講義資料、希望問題数と一緒にAIへ渡してJSONを作ります。
4. 生成されたJSONを読み込み、登録前に内容を確認します。
5. 科目と出題数を選び、学習を開始します。

右上の「自動・ライト・ダーク」で表示を切り替えられます。選択はこのブラウザに保存されます。

アプリ本体に講義資料や個人の記録は含まれていません。
問題と学習記録は各端末のブラウザに保存され、端末間では同期しません。
科目を書き出して問題を共有できますが、書き出しには学習履歴は含まれません。
ブラウザのデータ削除や別のURL・ブラウザへの切り替えで、前の記録を使えなくなる場合があります。

## 更新

このリポジトリのmainブランチが公開版です。同じ公開URLで互換性を保つ通常の更新では、端末に保存した問題と学習記録を維持します。
新版の準備ができると画面に案内が出ます。学習を終えてアプリの画面をすべて閉じ、開き直すと更新されます。
オフラインの間は端末に保存された版を使い、次回オンラインになったときに新版を確認します。
コードや保存形式を変更するときは、互換性の検査を行い、配布ビルドでservice-worker.jsのCACHE_VERSIONを更新してください。
過去の版はGitの履歴に残します。保存形式を変えた後の巻き戻しは別途互換性の確認が必要です。

アプリ内にAI接続やAPIキーはありません。問題の作成は利用者が選んだAIサービスで行います。
